Notes
- GBFS snapshot (S2) reflects the station network on the download date; stations that closed during 2025
  are recovered from trip data and the status archive.
- Status archive timestamps are UTC; all other time data converted to America/New_York in processing.
- MTA query: SELECT transit_timestamp, station_complex_id, station_complex, borough, latitude, longitude,
  sum(ridership), sum(transfers) GROUP BY those columns, one query per 7-day window.

KNOWN DATA ISSUES (to document in the data-quality report)
  - Station-status archive has NO data for 17-27 July 2025 (11 days, gap in the source archive);
    other months average ~85-90 snapshots per day (~16 minutes apart). Status is change-based:
    a station row is written only when its status changes.
  - Status file for January also contains 13 snapshots from 31 Dec 2024 (UTC boundary) - filter.
  - Central Park LCD has hourly gaps (7,677 rows vs ~8,760 hours); use LaGuardia as fallback.
  - NYC "Permitted Event Information" current dataset (tvpp-9vvx) holds only upcoming events (0 rows
    for 2025); all 2025 events come from the historical dataset (bkfu-528j).
  - ACS .dat files are national; filter GEO_ID to New York State tracts (prefix 1400000US36).
